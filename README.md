# 🏢 AI 지휘실 · 실사 오피스 본부 (v4)

실제 오피스 사진 위에 **gene 대표 + AI 역할·도구 19개(총 20명)** 의 자리·상태 태그와
말풍선이 떠 있는 **살아 움직이는 사무실 웹앱**입니다.

**v4 — 사진이 아니라 '살아있는 장면'** (2026-11-17)
- 사진 구도와 이름표(AR 마커) 좌표는 그대로 두고, 사람·로봇 영역만 페더 마스크로 아주 작게 변형해
  **호흡·몸 기울기·고개 끄덕임**을 넣었습니다(간헐적 제스처 포함, 8초 주기).
- **모니터 화면**: 코드 줄이 천천히 흐르고 커서가 깜빡이며 화면 밝기가 숨 쉰다.
- **창밖**: 밤에는 도시 불빛이 반짝이고 항공기 불빛이 지나가며, 낮에는 빛 결이 천천히 흐른다.
- **공기**: 부유 먼지·빛 입자가 떠다니고, 실내등·화면 글로우가 미세하게 맥동한다.
- 카메라 호흡(드리프트)은 기존대로 유지되고, 확대/이동·시간대 전환과 충돌하지 않는다.
- GIF/MP4도 같은 모션으로 다시 구웠다: `assets/ai-office-threads.gif`(8초·1000×667·무한루프),
  `assets/ai-office-threads.mp4`(8초·1200×800).

우측 패널에서 오피스·AI 업무·직원 현황·**👔 자문단**·**⚡ 도구**·활동 로그와 함께
**🎤 음성 지휘**로 일을 지시할 수 있습니다.
설치형 앱(PWA)으로 구성되어 있어 휴대폰 홈 화면에 추가하면 주소창 없는 앱처럼 열립니다.

상단 바 오른쪽 **`📋 체험단 비서`** 버튼을 누르면 체험단·이벤트 D-day 비서
(`https://gene4517-bot.github.io/ai-office/event-assistant/`)로 바로 넘어갑니다(2026-11-18 추가, `sw` v12).
비서 화면에서는 `⋯` 메뉴 → **AI 지휘실로** 로 돌아옵니다.

## 바로 열기

- `index.html` 을 브라우저로 열면 됩니다. (로컬 파일로 열어도 `status.json` 을 못 읽는
  환경이면 **index.html 안에 내장된 기본 데이터**로 자동 전환됩니다.)
- 서버로 띄우면 `status.json` 을 실제로 읽고 20초마다 자동 반영합니다.
  ```
  python3 -m http.server 8000 --directory ai-office
  # http://localhost:8000
  ```

## 📱 앱으로 설치 (PWA)

배포 주소: **https://gene4517-bot.github.io/ai-office/**

| 브라우저 | 설치 방법 |
| --- | --- |
| 갤럭시 **Chrome** | 주소창 오른쪽 설치 아이콘(모니터↓) 또는 ⋮ 메뉴 → **앱 설치** |
| **삼성 인터넷** | 하단 ≡ 메뉴 → **홈 화면에 추가** |
| PC Chrome/Edge | 주소창 오른쪽 **설치** 아이콘 |

- 설치하면 주소창·브라우저 버튼 없이 **standalone(전체 화면)** 으로 열립니다.
- 홈 화면 아이콘: 다크 웜톤 배경 + 금색 마이크 + 음성파 아치 (192 / 512 / maskable / 180 / ico).
- 앱 이름(홈 화면 표시)은 **AI 지휘실** — `<title>`, `manifest.short_name` 모두 4글자로 축약.
- 앱 아이콘을 길게 누르면 바로가기 **🎤 음성 지휘**, **직원 현황** 이 나옵니다.
- 음성 지휘로 바로 열기: **https://gene4517-bot.github.io/ai-office/?tab=voice**
- 서비스 워커는 **네트워크 우선**입니다. `status.json` 은 캐시에 저장하지 않으므로
  앱을 열 때마다 최신 사무실 상태를 읽습니다. (오프라인일 때만 캐시로 대체)

| 탭 | 하는 일 |
| --- | --- |
| ① EXIF 제거 & 모자이크 | 사진을 Canvas로 다시 그려 위치·기기 정보(EXIF/GPS)를 없애고, 손가락으로 문질러 얼굴·계좌번호를 모자이크/블러 처리 후 JPG·PNG 저장 |
| ② URL 추적 제거 | utm_* · igshid · fbclid · NaPm · trackingCode · src · spec 등 40여 개 추적값 제거, 짧은 공유 링크(l.threads.com 등) 안쪽 주소 풀기, 원클릭 복사. 쿠팡 파트너스처럼 리다이렉트가 수수료 표시인 경우 안내 표시 |
| ③ PDF ↔ 이미지 | 이미지 여러 장 → PDF 1개(A4 여백 / 원본 비율, 화질 선택) · PDF → 페이지별 PNG·JPG(1080·1600·2400px), 개별 저장·전체 ZIP |
| ④ 압축 & 포맷 변환 | 화질 슬라이더 + 최대 너비로 여러 장을 한 번에 줄이고 JPG·PNG·WebP로 변환, 원본 대비 절감률 표시, 전체 ZIP |
| ⑤ QR 생성 | URL·텍스트·와이파이(SSID/비밀번호/암호화) QR을 만료·광고 없이 생성, 512·1024·2048px PNG 저장 (한글 UTF-8) |
| ⑥ SNS 비율 리사이즈 | 1:1 · 4:5 · 16:9 · 9:16로 사진을 자르지 않고 여백(블러·흰색·검정)을 채워 저장, 긴 변 1080·1440·2048px |
| ⑦ 워터마크 일괄 삽입 | 기본 `@ogenegun` 등 문구를 9곳 위치·크기·투명도·색으로 여러 장에 한 번에 삽입 |

## 🏢 AI 팀 통합 회의실 (`room.html`) — 2026-11-23 추가

주소: **https://gene4517-bot.github.io/ai-office/room.html**
(앱 상단 맨 앞 `🏢 통합 회의실` 버튼으로도 열립니다)

AI들이 각자 다른 화면에서 따로 답하던 것을 **한곳(GitHub Issues)** 에 모으는 디스코드 스타일 회의실입니다.

- **백엔드 = GitHub Issues**: 저장소 `gene4517-bot/ai-office` 의 `team-room` 라벨 이슈가 곧 스레드입니다.
  `api.github.com` 을 브라우저에서 직접 읽어 **폰·PC 어느 기기에서 열어도 같은 스레드·같은 댓글**을 봅니다. 서버가 없습니다.
- **화면**: 다크 디스코드 톤(`#1e1f22`/`#2b2d31`/`#313338`), 왼쪽 채널바 + 오른쪽 메시지. 모바일 390px에서는 채널바가 드로어(☰)로 접힙니다.
- **역할 아바타·배지**: 댓글 첫 줄의 `[역할: 해이]` / `[역할: 클로드]` 를 읽어 아바타·이름·배지·색을 자동으로 붙입니다. `@해이` 같은 멘션은 역할 색으로 강조됩니다.
- **글쓰기 3가지**
  1. `✍️ GitHub에서 바로 답글` — 토큰 없이 1탭으로 그 이슈 페이지 이동(GitHub 로그인 상태면 바로 등록)
  2. `🔑 GitHub 토큰` 을 한 번 저장(`localStorage`, 서버 전송 없음)하면 회의실 안에서 역할을 고르고 **바로 GitHub 댓글로 등록**
  3. `📋 다른 AI에게 넘길 프롬프트 복사` — 지금 스레드의 안건·댓글 전체를 한 번에 복사해 무료 AI에 붙여넣고, 답을 다시 `[역할: …]` 형식으로 가져옵니다
- **한곳에 모아보기**: `📊 지휘실-현황`(status.json 요약), `🧰 모든-도구-모음`(AI 지휘실·음성 지휘·gene 덱·체험단 비서·7종 유틸·4X 플래너·노션 허브 바로가기)
- **실패 대비**: 읽기 한도(시간당 60회, 토큰을 넣으면 5,000회) 초과·네트워크 실패 시 안내 배너 + 마지막으로 성공한 화면을 저장해 보여줍니다.

```
# 스레드 만들기 (GitHub CLI)
gh issue create -R gene4517-bot/ai-office --label team-room --title "[안건] …" --body-file body.md
gh issue comment <번호> -R gene4517-bot/ai-office --body-file comment.md   # 첫 줄에 [역할: 해이]
```

- 서비스 워커 `ai-office-v15` 가 `room.html` 을 프리캐시합니다. 기존에 앱을 설치해 썼다면 새 버전은 자동으로 갱신됩니다.

## 📊 데일리 트렌드 뷰어 (`trends.html`) — 2026-11-24 추가

주소: **https://gene4517-bot.github.io/ai-office/trends.html**
(회의실 `🧰 모든-도구-모음` · 지휘실 오피스 탭 `📊 데일리 트렌드 뷰어` 카드로도 열립니다)

유튜브·구글 트렌드·뉴스·커뮤니티에서 매일 모은 트렌드를 카드로 보는 화면입니다.

- **수집(무료 공개 피드만 · 키·로그인·유료 API 없음)**
  1. 구글 트렌드 한국 일일 급상승 검색어 RSS — `trends.google.com/trending/rss?geo=KR`
  2. 유튜브 공개 검색 결과 — 키워드 `살림 꿀팁`·`주방 정리 수납`·`가전 추천`·`AI 활용 방법`·`핫딜 특가`·`속보 이슈`
     (이번 주 업로드분 + 인기 영상을 최신 가중치로 섞어 정렬)
  3. 구글 뉴스 한국 주요 뉴스 RSS — `news.google.com/rss?hl=ko&gl=KR&ceid=KR:ko`
  4. 뽐뿌 게시판 RSS — 커뮤니티 핫딜
- **자동 갱신**: `.github/workflows/update-trends.yml` 이 매일 **06:10(한국시간)** 에 `scripts/collect_trends.py` 를 돌려
  `trends-data.json` 을 커밋하고 `main`·`gh-pages` 두 브랜치에 함께 올립니다(Pages 자동 반영). `workflow_dispatch` 로 직접 실행도 됩니다.
- **한 소스가 막히면** 그 소스는 직전 수집분을 `이전 수집분` 표시와 함께 그대로 보여줍니다(화면이 비지 않음).

## status.json 갱신 방법 (해이가 직접 수정)

`updated_at` 을 바꾸고 필요한 값만 고치면 20초 안에 화면에 반영됩니다.
(페이지를 연 상태에서도 자동 반영 / 새로고침하면 즉시)

- 상단 **`마지막 갱신`** 배지는 `updated_at` 을 그대로 보여 줍니다.
- 상단 통계(`기록된 처리`·`진행 중`·`대기`)는 아래 `tasks` 의 `state` 를 **직접 세어** 표시하고,
  `AI 역할·도구` 수는 `staff` 중 `ceo` 를 뺀 수입니다. (`stats` 값은 `tasks` 가 없을 때만 쓰입니다)
- 상단 통계 카드 4칸은 **터치/클릭 필터**입니다(2026-11-18 추가, `sw` v11).
  - `기록된 처리` → **AI 업무** 탭에서 `state: done` 만 모아 보기
  - `진행 중` → **AI 업무** 탭에서 `state: progress` 업무 + 그 일을 맡은 직원 목록
  - `대기` → **AI 업무** 탭에서 `state: waiting` 업무 + 대기 중인 직원 목록
  - `AI 역할·도구` → **직원 현황** 탭에서 전체 역할·도구(부서별) 보기
  - 선택한 카드는 금색 테두리로 표시되고, 배지(`필터: 진행 중 · 진행 중만 보기 6건` + `전체 보기 ✕`)가
    탭 아래에 뜹니다. 같은 카드를 다시 누르거나 `전체 보기 ✕` 를 누르면 해제되고,
    다른 탭을 직접 고르면 필터도 함께 풀립니다. 모든 카드가 `<button>` 이라 키보드(Tab·Enter)로도 됩니다.

```json
{
  "updated_at": "2026-11-15 09:00",
  "stats": { "done": 31, "progress": 8, "waiting": 6 },
  "board": {
    "title": "오늘의 파이프라인",
    "rows": [ { "label": "이벤트·설문 접수", "value": "18", "unit": "건", "tone": "ok" } ],
    "ticker": "전광판에 흐르는 한 줄 안내"
  },
  "tasks": [
    { "title": "업무 이름", "owner": "해이", "state": "progress", "progress": 70, "note": "메모" }
  ],
  "staff": [
    { "id": "haei", "status": "working", "task": "현재 하는 일", "mode": "auto", "done": 12, "bubbles": ["하고 싶은 말"] }
  ],
  "logs": [ { "time": "09:00", "who": "해이", "text": "한 일", "tone": "ok" } ]
}
```

## 🎤 음성 지휘 탭

폰에서 말로 일을 지시하면 담당 AI에게 자동 배정되는 화면입니다.

1. **말하기 / 입력** — 큰 마이크 버튼(Web Speech API `ko-KR`)을 누르고 말하면 바로 텍스트가 되고,
   프리셋(PC 화면 캡처 · PC 오디오 폴더 정리 · 오늘 이벤트 요약 · 블로그 초안 · 출석체크)도 있습니다.
2. **자동 배정** — 키워드로 담당을 고릅니다.
   PC 캡처·파일 → 루아, PC 상태·앱 실행 → StarDesk, 폰 앱·출석 → Buddy,
   이벤트·설문·인증 → 해이, 블로그 → Manus, 스레드 → Muse, X → Grok,
   유튜브 → Gemini, 모니터링 → Hark, 문자 확인 → Instinct, 자율 에이전트 → vooy, 설계·코드 → Claude,
   조사 → Cue, 보안 → Tailscale, 아이디어·초안 → ChatGPT (그 외 → 해이).
3. **원클릭 실행**
   - PC 일이면 **PC 브릿지**로 바로 전송합니다. (`pcctl.cfg.v1` 에 저장된 주소·토큰을 그대로 사용
     — PC 컨트롤 대시보드에서 한 번만 저장하면 됩니다: 캡처 `/api/capture`, 상태 `/api/status`,
     앱 실행 `/api/launch`, 클립보드 `/api/clipboard`)
   - AI 지시면 **노션 지휘 프롬프트**를 만들어 **[복사]** 한 번으로 다른 AI 앱에 붙여넣게 합니다.
4. **기록** — 최근 지휘 12건을 기기에 저장(localStorage)하고, 활동 로그에도 남깁니다.
