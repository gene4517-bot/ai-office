연결 설정

PC에서 start_bridge.bat을 실행하면 콘솔에 주소와 보안 토큰이 나옵니다. 그 두 값을 아래에 넣고 저장하세요. 값은 이 브라우저(localStorage)에만 저장되고 서버로 보내지 않습니다.

같은 Wi-Fi면 http://PC의IP:8765 · 이 PC 자체라면 http://localhost:8765 · Tailscale을 쓰면 http://100.x.x.x:8765
PC 폴더의 config.json 을 메모장으로 열면 token 항목이 있습니다. 전체를 복사해 붙여 넣으세요.
‘노션 본부’ 타일을 눌렀을 때 열 주소입니다. 비워 두면 notion.so 홈으로 갑니다.
📱
S25 울트라 원격 연결 공기계(노트10) 덱 버튼 → S25 울트라 실행 · MacroDroid 웹훅
끝의 / 는 자동으로 지워집니다. 매크로 주소 전체를 붙여 넣어도 마지막 식별자 (pickle·bixby·threads·youtube·mute·ping)는 자동으로 정리됩니다.
처음이면 여기 — 5분 연동 가이드
  1. S25 울트라에 MacroDroid(무료)를 설치하고 엽니다.
  2. 매크로 추가 ＋ → 트리거에서 웹훅 (URL) 을 고릅니다.
  3. 트리거의 식별자(Identifier) 칸에 아래 6개 중 하나를 정확히 입력합니다.
  4. 액션 추가에서 할 일을 고릅니다 — pickle·bixby·threads·youtube는 ‘앱 실행’, mute는 ‘음량 0 / 무음 모드’, ping은 ‘알림음·진동’.
  5. 저장한 뒤 웹훅 화면의 주소에서 기기 ID까지만 복사해 위 칸에 붙여 넣습니다.
  6. 같은 방법으로 6개 매크로를 만들고, 아래 연결 테스트(ping) 로 확인합니다.

웹훅은 S25가 인터넷에 연결돼 있어야 동작하고, Google Play 서비스가 필요합니다. 주소를 아는 사람은 누구나 S25를 움직일 수 있으니 이 화면 밖으로 공유하지 마세요.
