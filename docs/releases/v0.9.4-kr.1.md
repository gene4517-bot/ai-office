# 홈드로이드 KR 0.9.4-kr.1 (gene 홈서버)

갤럭시 노트10을 24시간 홈서버로 쓰기 위한 **한국어판** 첫 배포입니다. 앱 화면·웹
대시보드·알림을 한국어로 다듬고 `gene 홈서버`로 브랜딩했습니다.

## 내려받기

| 파일 | 쓰는 곳 |
| --- | --- |
| `homedroid-0.9.4-kr.1-arm64-v8a.apk` | 갤럭시 노트10·S25 울트라 등 arm64 휴대폰 (**권장**, 용량 작음) |
| `homedroid-0.9.4-kr.1-universal.apk` | CPU를 모르거나 한 파일로 받고 싶을 때 |
| `SHA256SUMS` | 받은 파일이 그대로인지 확인 |

휴대폰에서 직접 AI 모델을 돌리는 런타임(`llama-runtime-arm64-v8a.tar.gz`)은 이 릴리스에
없습니다. 그 기능을 쓰지 않는 이상 설치는 그대로 됩니다.

- 안드로이드 10 이상(minSdk 29, targetSdk 36).
- 패키지 이름이 `dev.homedroid.kr`이라 영문판 Homedroid와 **함께** 설치됩니다.
- 앱은 `gene-homedroid-kr` 키로 서명했습니다. 이후 업데이트도 같은 키로 서명하므로 앱 안의
  "업데이트" 기능으로 덮어 설치할 수 있습니다.

## 설치 (갤럭시 노트10)

1. 노트10 브라우저에서 이 릴리스의 `...-arm64-v8a.apk` 링크를 눌러 내려받습니다.
2. 내려받은 파일을 열면 "출처를 알 수 없는 앱" 안내가 나옵니다. **설정 → 허용**을 눌러
   Chrome(또는 쓰는 브라우저)에 설치 허용을 켠 뒤 다시 설치합니다.
3. Play 프로텍트가 "알 수 없는 앱" 경고를 띄우면 **무시하고 설치**를 고릅니다(직접 만든
   서명 APK라 정상입니다).
4. 설치 후 앱을 열고 **설정 → 서버**에서 SSH·웹 호스팅·대시보드 포트를 확인합니다.
   기본값은 대시보드 `http://<휴대폰 IP>:8800`, SSH/SFTP `8022`, 웹 호스팅 `8080`입니다.

## 24시간 서버로 쓰기

- 휴대폰 설정 → 애플리케이션 → **홈드로이드 KR** → 배터리 → **제한 없음**.
- 앱 설정에서 **부팅할 때 시작**을 켭니다.
- 안드로이드 12에서는 "자식 프로세스 제한"을 풀어야 서버가 안 죽습니다(앱의 안내 참고).
- 재부팅하면 IPCam 카메라 접근 허용을 한 번 다시 눌러야 합니다.

## 바뀐 점

- 웹 대시보드 전체 한국어화(개요·파일·앱·저장소·네트워크·클러스터·AI·설정), 한국어/영어 전환.
- 앱 화면·알림·권한 안내 문구 한국어화. API 오류 메시지 일부는 영어로 남아 있습니다.
- `gene 홈서버` 브랜딩과 개요 화면의 "노트10 24시간 서버 팁" 카드.
- 앱 목록(`apps.json`) 모듈 이름·설명 한국어화.
- 업데이트 확인 주소를 이 저장소(`gene4517-bot/ai-office`)로 변경.
- arm64-v8a 전용 빌드로 APK 용량 축소, universal APK도 함께 제공.
