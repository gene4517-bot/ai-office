# 홈드로이드 KR 0.9.4-kr.1 (gene 홈서버)

쓰지 않는 안드로이드 휴대폰(갤럭시 노트10 등)을 24시간 홈서버로 쓰기 위한 **한국어판**입니다.
원작 [sudiptacmd/homedroid](https://github.com/sudiptacmd/homedroid) (GPL-3.0)를 한글화하고
`gene 홈서버` 스타일로 다듬었습니다.

## 내려받기

| 파일 | 대상 |
| --- | --- |
| `homedroid-0.9.4-kr.1-arm64-v8a.apk` | 갤럭시 노트10, 갤럭시 S25 울트라 등 arm64 안드로이드 10 이상 (**권장**) |
| `homedroid-0.9.4-kr.1-universal.apk` | 같은 바이너리를 한 파일로 받고 싶을 때 |

패키지 이름이 `dev.homedroid.kr`이라 **영문판 Homedroid와 함께 설치**됩니다. 기존 앱과 데이터는
그대로 두고 한국어판을 따로 쓸 수 있습니다.

## 이번 판에서 바뀐 것

- **웹 대시보드 전체 한국어화**: 개요, 모듈, 배포, 파일, 터미널·SSH, 네트워크, AI·루틴, IPCam,
  모든 카메라, 원격 부팅, 클러스터, 설정, 그리고 Cloudflare·Tailscale·AdGuard Home 설치 안내까지.
- **앱 화면 한국어화**: 개요(서버 상태), 설정, 앱 목록, 웹 제어판, 홈 화면 위젯, 서비스·카메라 알림.
- **`gene 홈서버` 브랜딩**: 사이드바·로그인 화면·문서 제목, 앱 이름 `홈드로이드 KR`.
- **개요 화면에 "노트10 24시간 서버로 쓰는 팁"** 카드 추가: 배터리 보호(85%), 배터리 최적화 예외,
  자식 프로세스 제한 해제, 재부팅 후 IPCam 재허용, SD카드 활용.
- **모듈 목록 한국어화**: Jellyfin, qBittorrent, Home Assistant, Immich, AdGuard Home의 이름·설명·
  저장소 이름.
- 빌드는 **arm64-v8a만** 해서 시간을 줄였고, APK는 이 저장소의 키로 서명해 바로 설치됩니다.
- 업데이트 확인이 이 저장소의 Release를 보도록 바꿨습니다.

## 설치

1. 위 APK를 휴대폰에서 내려받아 설치합니다. (처음 한 번 "출처를 알 수 없는 앱 허용"이 필요합니다.)
2. 앱을 열고 **서버 시작**을 누른 뒤, 같은 Wi-Fi의 브라우저에서 표시된 주소(`http://<휴대폰 IP>:8800`)로
   대시보드에 접속합니다.
3. 설정에서 **부팅할 때 시작**, **배터리 설정 → 제한 없음**을 켜 두면 24시간 서버로 쓰기 좋습니다.
4. 재부팅 후에는 **카메라 접근 허용**을 다시 눌러야 IPCam이 동작합니다.
