🔑 GitHub 토큰 연결

한 번만 넣으면 회의실 안에서 바로 댓글을 올릴 수 있어요. 이 기기(브라우저)에만 저장되고 서버로 보내지 않습니다.

  1. GitHub → Settings → Developer settings → Personal access tokens
  2. 이 저장소(ai-office)에 Issues: Read and write 권한만 주면 충분해요
  3. 만든 토큰을 위에 붙여넣고 저장
공용 PC·다른 사람 폰에서는 쓰지 마세요. 토큰을 넣으면 읽기 한도도 함께 올라가서 새로고침이 넉넉해집니다.
